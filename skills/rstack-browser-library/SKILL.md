# rstack-browser-library

Read [browser library](../../docs/browser-library.md) for tab, group or bookmark curation. Bind the requested browser, profile and scoped collection before changing it.

Use one authorized writer. Preserve exact URLs, distinct conversation identities, existing memberships and drafts. Reconcile every scoped original with its destination. Use unknown dates when source dates are unavailable.

Return a coverage ledger and destination readback. Do not open held assessment content to classify a tab. Preserve reserved windows and other tasks' browser ownership. This skill does not authorize deletion, account changes or replacing the user's chosen browser.
