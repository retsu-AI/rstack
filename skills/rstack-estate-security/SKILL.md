# rstack-estate-security

Read [estate security](../../docs/estate-security.md) for an explicitly scoped review of accounts, devices or active runtimes. Bind asset ownership, allowed access and current holds through the existing security owner.

Build a private coverage register. Distinguish configured, installed and loaded versions, and match applicable current primary advisories to exact builds and conditions. Missing fields stay unknown. Outdated, affected, exposed and demonstrated compromise are separate conclusions.

Return per-asset findings, evidence limits and the authorized next action. Preserve intended remote and file access. This skill does not resume paused audits or grant scans, credential changes, access revocation or remediation.
