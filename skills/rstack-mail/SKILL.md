# rstack-mail

Read [mailbox rules](../../docs/mail-rules.md) for bounded inbox classification or rule acceptance. Inspect full threads and sent replies, then bind actions to exact message identities and the selected account.

Reuse the mail owner and one authorized writer. Preserve requested labels, receipts, codes and sender exceptions. Authentic mail can still be deliberately unwanted. Keep uncertain classifications unchanged and use a non-author reviewer for consequential actions when required.

Return before-and-after identities, classification dispositions and rule evidence. Saved rules and static matches do not prove new-arrival behavior. This skill does not create a cleanup schedule, send test mail or authorize account setup and forwarding.
