# rstack-publish-privacy

Read [publication privacy](../../docs/publication-privacy.md) when an artifact is about to cross a sharing boundary. Bind the original task, actual artifact set, destination ownership and audience before preparing a publication decision.

Reuse the existing delivery owner and outcome register. Keep source preservation, sanitization, publication and recipient acceptance separate. A private company repository can have a different audience from personal storage. A text-only check does not clear uninspected media or history.

Return an allowed, rejected or incomplete sharing decision with exact scope and remaining gaps. Continue authorized preparation around an unapproved effect. Preserve current holds and existing publication authority; this skill grants neither publication nor destructive remediation.
