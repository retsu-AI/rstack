# rstack-coordinate

Read [coordination](../../docs/coordination.md). Inspect existing ownership before dispatch. Assign one writer per artifact, disjoint helper outputs and a genuine non-author reviewer when required. Use [the brief](../../templates/worker-brief.md) to carry current context and authority.

Verify an actual first action and then an artifact/test checkpoint. Creation, active labels and saved goals do not prove execution. Respect current user limits on agents, environments, models, spending and schedules.

For native-goal assignments, follow [goal binding and lifecycle](../../docs/completion-contract.md). Retain the compatible goal and actual readbacks. Unavailable capability or a conflicting goal is a named dependency, not creation authority.
