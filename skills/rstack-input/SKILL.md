# rstack-input

Read [physical input](../../docs/physical-input.md) for keyboard, dictation or peripheral-control acceptance. Record the intended physical action and output, active profile and application before changing a binding.

Preserve working mappings and rollback state. Separate saved configuration, registered runtime binding and observed physical behavior. Inspect press, hold, release and reconnect for the requested control; use the conditional media checks only when capture is in scope.

Return the exact tested actions and observation limits through the existing device or session owner. A stopped process does not prove microphone or camera release. Preserve reserved windows, active recordings and existing permissions.
