# rstack-executors

Read [shared executors](../../docs/shared-executors.md) when qualifying shared CI or worker capacity. Map the actual admission paths, trust classes and job identities to the existing capacity owner.

Use the current scheduler and register. Keep job admission, useful execution, cancellation, child cleanup and released capacity separate. Preserve original setup, source and durable state when classifying rebuildable job output.

Return a bounded lifecycle verdict with normal and rejecting evidence, unresolved resources and the exact resumption trigger. This skill adds no scheduler, daemon, account, grant or spending authority. Preserve active workloads and current resource limits.
