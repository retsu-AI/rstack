# Check artifact privacy before publication

Use this procedure when requested artifacts will move to a repository, channel, report, file share or another audience. For private-to-reusable extraction, retain the existing company G04 method. Use this additional check on the actual transfer.

## Bind the transfer

Record the original task, current owner, artifact revisions, destination identity and ownership, intended audience, visibility, transport and existing action authority. Reuse the outcome register. Separate personal storage, a shared private repository and a public destination.

Build an artifact manifest for the requested transfer. Include relevant tracked files, selected history or refs, issues or comments, logs, generated bundles, screenshots, recordings and binary documents. A bounded manifest is sufficient when it states its exclusions. Do not start a new estate-wide scan.

## Inspect and decide

1. Compare each artifact with the original purpose and permitted audience. Classify private identifiers, customer material, secrets, case records and licensed content using the actual task boundary.
2. Inspect each included format through a suitable reader. Record text, image, audio and video coverage separately. A hash or negative text search cannot establish that uninspected pixels or recordings are clear.
3. Prepare a sanitized copy or exclude an artifact when appropriate. Preserve the original privately according to its retention rules. Keep private provenance outside reusable source.
4. Reject a destination mismatch even when the content is sanitized. Recheck changed bytes and destination visibility before the authorized transfer.
5. Preserve the transfer receipt separately from privacy acceptance. Reconcile an uncertain send before retry through [recovery](recovery.md).

If an exposure needs remediation, give the existing owner the exact affected artifacts and audience. Preserve legitimate mixed work. Branch deletion does not establish erasure from history or other copies. A closed incident is not authority to reopen it.

## Return evidence and acceptance

Return the manifest and exclusions, source and destination identities, inspected formats, sanitization decisions, remaining unknowns and the permitted next action. Apply [verification](verification.md) to the frozen artifact set and required non-author verdict.

| Case | Required result |
|---|---|
| Normal | An authorized sanitized draft reaches the intended audience at the reviewed revision, with a separate delivery receipt. |
| Reject | A draft aimed at a different organization's repository is rejected before transfer, even if its text contains no detected personal data. |
| Incomplete | A bundle includes uninspected screenshots. Its privacy acceptance remains open for those images rather than inheriting the text result. |

These are acceptance exercises for a future authorized task. This reference itself has not inspected or published an artifact.
