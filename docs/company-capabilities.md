# Company capability extraction

These 46 contracts are reusable procedures and skill candidates, not 46 installed or runtime-validated skills. Reuse the existing owner, register and relevant domain skill. `reuse` means route to inspected existing guidance; `extend` means add this company-specific contract to that guidance; `new` identifies a procedural gap in the inspected material. Absence from the inspected skill inventory is not proof of global absence. The procedures are generalized from source reports and plans; reported product behavior has not been rerun. Private source mapping is kept outside reusable source.

For every row, use the [company operating loop](company-operations.md) and [operating-unit template](../templates/company-operating-unit.md). Validate any new standalone skill with Skill Creator and a bounded independent behavior exercise before claiming installation or operational readiness. Titles below are proposed skill names, not registered entrypoints.
