# Curate a browser library without losing identity

Use the browser and control route the user selected. Keep the existing browser owner and one writer. Scope the task to the requested tabs, saved groups, folders or bookmarks rather than the whole profile by default.

## Inventory the originals

Record the actual browser and profile, window or group identities, exact URLs, item IDs when available, titles, existing membership and relevant drafts. Respect reserved windows and other tasks' ownership. A tab title is not a conversation identity.

Use source dates only when available. A rename, capture time or current tab order does not establish when the content was created. Put undated items in an explicit unknown-date group.

## Reconcile destinations

1. Build a source-to-destination mapping for every scoped original. Distinct conversation IDs, query parameters and fragments can carry meaningful identity, so do not deduplicate by title or a shortened URL.
2. Classify using permitted metadata and content. If assessment content or another item is held, keep it closed and retain its existing identity with an unresolved classification when necessary.
3. Add or move the authorized items while preserving originals, drafts and existing memberships required by the task. Confirm the destination's actual behavior before assuming a move retains another group.
4. Read back complete destination membership and exact URLs. Follow pagination or group expansion needed for the declared scope. Reconcile changes made by the user during the operation.
5. Handle duplicate removal, closing tabs or deleting originals only within current authority and after identity and destination preservation are established. A successful bookmark write alone does not authorize closure.

If the supported browser tool cannot enumerate a required collection, preserve that gap and finish independent readable work. Do not manufacture completeness from the first visible screen.

## Return evidence and acceptance

Return the original population, item-to-destination ledger, unknown-date items, retained originals, destination membership and unresolved gaps. Use [verification](verification.md) for the required non-author check. A completed organization pass creates no recurring browser manager.

| Case | Required result |
|---|---|
| Normal | Every selected original has the intended destination with its exact URL. Existing required memberships and drafts survive. |
| Reject | Two same-title conversations with different IDs collapse into one bookmark, or a reserved window changes. The pass fails for the affected items. |
| Incomplete | A saved group cannot be enumerated. Report the known count and unread collection instead of claiming complete coverage. |

Keep account details and private browsing content out of reusable examples. Source pointers belong in the private task evidence.
